# 🛒 Zepto E-commerce SQL Data Analysis

## 📌 Project Overview

A practical **SQL Data Analysis project** using a Zepto e-commerce inventory dataset to analyze **product pricing, discounts, stock availability, inventory, and category performance**.

The project follows a real-world analytics workflow:

**Data Exploration → Data Cleaning → Business Analysis → Insights**

---

## 🎯 Objectives

* Explore and understand e-commerce inventory data
* Identify missing, invalid, and inconsistent data
* Analyze product pricing and discount patterns
* Examine in-stock and out-of-stock products
* Analyze inventory across product categories
* Estimate potential revenue based on available inventory
* Compare products using price-per-gram analysis
* Identify products with multiple SKUs

---

## 🛠️ Tools & Technologies

* **PostgreSQL**
* **SQL**
* **pgAdmin**
* **Git & GitHub**

---

## 🔍 Analysis Performed

### Data Exploration

* Record and category analysis
* NULL value checks
* Stock availability analysis
* Multiple SKU identification

### Data Cleaning

* Invalid/zero-price identification
* Removal of invalid records
* Price conversion from paise to rupees
* Data validation after transformation

### Business Analysis

* Top products by discount percentage
* High-priced out-of-stock products
* Potential revenue by category
* High-MRP products with low discounts
* Average discount by category
* Price-per-gram analysis
* Product weight classification
* Total inventory weight by category

---

## 💡 Key Insights

The analysis provides visibility into:

* **Pricing & discount patterns**
* **Product availability**
* **Category-level inventory**
* **Potential inventory revenue**
* **Product value based on weight**
* **SKU-level product distribution**

These insights demonstrate how SQL can be used to support **inventory, pricing, and e-commerce business analysis**.
